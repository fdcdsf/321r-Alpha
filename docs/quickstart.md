# Быстрый старт

321r — отказоустойчивый кластер VPS: защищённый меш между серверами, общие базы данных
с автоматическим переключением, бэкапы по правилу 3-2-1 и Telegram-бот как панель
управления. Установка — одной командой с первого сервера, кластер любого размера
(минимум 3 ноды). Установщик делает всё сам; этот документ — всё, что нужно для старта.

## Что понадобится

| Что | Зачем | Минимум |
|---|---|---|
| 3 и более серверов (VPS) | кластер переживает потерю любого одного сервера | Debian 12/13 или Ubuntu 22.04/24.04/26.04 (смешивать можно), **полная виртуализация** (KVM/VMware/Hyper-V; OpenVZ/LXC не подойдут), 1 ядро / 1 ГБ (комфортно 2 ГБ) |
| Домен | панели, маскировка, сертификаты | любой, DNS у Cloudflare |
| Telegram-бот | панель управления и алерты | создать у @BotFather (2 минуты) |

Честные минимумы железа и бюджет памяти — в [resources.md](resources.md). Ядро кластера
живёт на трёх серверах по 1 ядру и 1 ГБ; панели и MongoDB просят ноды побольше.

## Установка одной командой

Зайдите по SSH на **первый** сервер от root и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/fdcdsf/321r-Alpha/master/install/bootstrap.sh | bash
```

Нет `curl` (свежая Debian)? Тогда `apt-get update && apt-get install -y curl`
либо wget-вариант:

```bash
wget -qO- https://raw.githubusercontent.com/fdcdsf/321r-Alpha/master/install/bootstrap.sh | bash
```

Это всё. Мастер-установщик спросит остальное и поставит систему **на все серверы
одновременно**. Подробный разбор вопросов мастера — в [deploy.md](deploy.md).

## Что спросит мастер

- адреса остальных серверов и их root-пароли (нужны один раз, чтобы заложить ключ;
  дальше пароли не нужны и отключаются);
- токен Telegram-бота и chat id владельца (узнать: @userinfobot);
- домен и Cloudflare-токен (можно пусто — тогда ставится только ядро кластера);
- Pangolin: автоматическая или ручная первичная настройка; EE-лицензия вводится
  скрыто (пустой ввод — без лицензии);
- Remnawave: `install` — панель на кластере, либо `connect` — существующая панель
  (например, дома за Newt через Pangolin): введите HTTPS-адрес и API-токен;
- файлы WARP `.conf` для обхода блокировки Telegram — по одному на каждый сервер
  (можно пусто и загрузить позже через бота);
- профиль ресурсов S/M/L и состав приложений (базы данных);
- установить ли Zabbix HA (нужен хотя бы один сервер ≥ 4 ГБ).

Либо, если привычнее с ноутбука: `git clone`, заполнить `install/inventory.conf`
и запустить `./install/install.sh` — та же машина шагов.

## Пока идёт установка (15–30 минут, можно пить чай)

Установщик проходит шаги сам, печатая ход дела: предпроверки и ключ межнодового
доступа → базовая подготовка (Docker, firewall, fail2ban, часы UTC) → меш AmneziaWG
(серверы видят друг друга по адресам 10.66.0.x) → Docker Swarm (все серверы —
менеджеры) → слой баз данных с VIP 10.66.0.99 и «мозгом» db-guard → бэкапы 3-2-1 →
Telegram-бот → DNS и сертификаты → панели → автоприёмка → финальная защита SSH.

Важно: любой шаг можно перезапустить — установщик идемпотентен, работающее не сломает:

```bash
./install/install.sh --from=db        # продолжить с шага db
./install/install.sh --check          # только автоприёмка
```

**Секреты.** Токен бота и пароли не попадают в git. Пароли баз установщик генерирует
сам и кладёт только на серверы (`/etc/db/secrets/`, права 600). Введённые пароли
серверов используются один раз и нигде не сохраняются.

## Приёмка

В конце печатается отчёт автоприёмки — все строки `✓`. Проверьте руками:

- в Telegram пришло меню бота — покрутите кнопки (📊 Статус, 💾 Бэкапы, 🗄 Базы);
- **в Telegram придёт файл «🔐 Памятка владельца»** — все пароли, ключи, секреты и
  ссылки одним файлом. Сохраните его в менеджере паролей или распечатайте; на серверах
  копия лежит в `/root/321r-pamyatka-*.txt` (права 600). Там же — код первичной
  настройки Pangolin (`setup token`): без него не пройти первый вход в панель;
- в режиме `install` Remnawave памятка содержит две разные ссылки:
  `https://sub.<домен>/<shortUuid>` — **страница для человека** с интерфейсом;
  `https://rem.<домен>/api/sub/<shortUuid>` — **сырая подписка** для VPN-приложения
  (в браузере она может выглядеть как технические данные);
- утром придёт дайджест, а при любой беде — алерт;
- бот показывает всё, что есть на серверах, само: новые базы, контейнеры и сервисы
  появляются без настроек (кнопка 🔄 Обновить).

Повторная проверка в любой момент: `./install/install.sh --check`.
